In drei Schritten startklar

  1. Herunterladen

    Die Version für Ihr Gerät laden. Ein Konto brauchen Sie nicht.

  2. Öffnen

    Beim ersten Start fragt Ihr Rechner einmal nach. Wie Sie bestätigen, steht auf jeder Programmseite.

  3. Loslegen

    Klassen anlegen oder aus einer Liste einlesen. Ausprobieren geht auch mit erfundenen Beispielklassen.

Ihre Daten bleiben auf Ihrem Gerät

Noten und Klassenlisten sind sensible Daten. Deshalb arbeiten die Programme ohne Server und ohne Konto.

  • Kein Server, kein KontoGespeichert wird nur auf Ihrem Gerät, bei Libretto zusätzlich verschlüsselt.
  • Keine Werbung, kein TrackingDie Programme senden nichts über Sie oder Ihre Klassen. Diese Website setzt keine Cookies.
  • Eine Ausnahme’namo. braucht für die Reisegruppe einen gemeinsamen Stand und nutzt dafür einen Server in der EU. Einzelheiten stehen in der Datenschutzerklärung.
