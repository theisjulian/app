Veröffentlichungsstand

Verglichen werden die Version in versions.json (das, was die Apps als „neueste Version“ sehen), das neueste Release bei GitHub und die erwarteten Dateien. Die Versionsnummer wird aus dem Release-Namen gelesen (z. B. „Libretto 0.9.4“).
